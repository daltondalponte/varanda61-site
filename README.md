# Varanda 61 - Site institucional

Site basico da Varanda 61 construido com Next.js (App Router) e Tailwind.

## Rodar localmente

```bash
npm run dev
```

Abra http://localhost:3000 no navegador.

## Estrutura principal

- Pagina inicial em `src/app/page.tsx`
- Estilos globais em `src/app/globals.css`

## Publicar na Vercel (dominio gratuito)

Ao publicar pela Vercel, seu site pode usar um subdominio gratuito no formato
`seu-projeto.vercel.app`.

## Ajustes rapidos

- Atualize textos e contatos na secao de Contato
- Troque cores e tipografia em `globals.css`
